Cross-Speaker Emotion Adaptation — Audio Samples

Note: The test set contains only one utterance per (speaker, emotion) pair. We therefore use the first 3 seconds of the ground-truth audio as the prompt (REF); if the utterance is shorter than 3 s, the entire clip is used. The synthesis task is then essentially a reconstruction of the original utterance from this short prompt.
Each sample: REF (3-second prompt) + GT (ground truth) + 4 backbones × 4 fine-tuning methods. CSP-FT denotes our proposed method. SS: speaker similarity (%, ↑)   ERS: emotion-recognition similarity (%, ↑)   WER: word error rate (%, ↓)
